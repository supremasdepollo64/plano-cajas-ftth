# Plano de cajas FTTH

Mapa web operativo para consultar cajas NAP/CTO de la red FTTH.

## Funciones incluidas

- Visualización de las cajas sobre OpenStreetMap.
- Búsqueda por nombre, grupo o descripción.
- Filtro entre ubicaciones verificadas y aproximadas.
- Detalle con coordenadas y enlace para llegar con Google Maps.
- Diseño adaptable a computadora y celular.

Los datos de partida están en `dist/data/cajas.kml`.
